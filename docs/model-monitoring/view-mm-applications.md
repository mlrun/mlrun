# Viewing the application monitoring

## Overview
The Monitoring Application View provides you with a comprehensive overview of your monitoring applications. You can view the existing applications, their status, and the corresponding monitoring results. The default time period is 24 hours. The maximum time period is one month. The data is updated every hour.
## General applications view
This view shows the list of available monitoring application and their status.
It also displays a chart showing the number of detections and possible detections for the requested period (for all the apps and all the model endpoints).
## Application Details
From the main view, press an app name to link to the App view, which includes: a List of all artifacts, and the monitoring app results and metrics.
You can also see the monitoring application metrics for all the model endpoints that are monitored.
