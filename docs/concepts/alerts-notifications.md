# Alerts and notifications 

{ref}`notifications` are used to notify you of system events on jobs (both scheduled and not), for example, start/finish of processes, and error messages; {ref}`alerts` are a generic mechanism that allows you to define more specific rules, such as an event X happens N times in T minutes, and can also be used for model monitoring.
